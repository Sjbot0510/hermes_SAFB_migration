\section{Data Structures}

\subsection{LatticeInfo}

A structure holding lattice parameters and metric tensors:

\begin{itemize}
    \item \texttt{Lx, Ly, Lz}: Lattice lengths (Å)
    \item \texttt{alpha, beta, gamma}: Lattice angles (degrees)
    \item \texttt{G[3][3]}: Reciprocal metric tensor
    \item \texttt{Ginv[3][3]}: Inverse metric tensor
    \item \texttt{dim}: Dimension (2 or 3)
\end{itemize}

\subsection{Star}

A structure holding star information:

\begin{itemize}
    \item \texttt{hkl[3]}: Canonical Miller indices
    \item \texttt{q2}: $|\mathbf{q}|^2$ (q-squared)
    \item \texttt{multiplicity}: Number of vectors in the star
    \item \texttt{closed}: 1 if closed under inversion
    \item \texttt{vectors[3][MAX\_STAR\_SIZE]}: Symmetry-equivalent vectors
    \item \texttt{vector\_keys[MAX\_STAR\_SIZE]}: Lexicographic keys
    \item \texttt{phase\_factors[MAX\_STAR\_SIZE]}: Phase factors
\end{itemize}

\subsection{SAFBBasis}

A structure holding the complete basis:

\begin{itemize}
    \item \texttt{n\_modes}: Number of modes (families)
    \item \texttt{modes[MAX\_MODES]}: Mode data
    \item \texttt{centrosymmetric}: 1 if inversion is in point group
    \item \texttt{inversion\_at\_origin}: 1 if inversion at origin
\end{itemize}

\section{API Usage}

\subsection{Basic Workflow}

\begin{enumerate}
    \item Create engine from space group file and lattice parameters
    \item Initialize (random or manual)
    \item Build field (inverse FFT)
    \item Output field to VTK
    \item Clean up
\end{enumerate}

\subsection{Example Code}

\begin{verbatim}
// Create engine from space group file
Engine *engine = engine_create(
    "examples/space_groups_3d/ia_3d.txt",
    "examples/lattice_cubic.txt");

// Random initialization with seed 42
engine_init_random(engine, 42);

// Build field on 64x64x64 grid
engine_build_field(engine, 64, 64, 64);

// Output field to VTK
engine_output_field(engine, "gyroid.vts");

// Clean up
engine_destroy(engine);
\end{verbatim}
